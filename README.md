# Chalk (Alpha v0.8)

Chalk is fully open source and **contributions are welcome!** Whether you're fixing a bug, improving the UI, adding a feature, or just giving feedback — you're helping build something meaningful.

### What you can help with
 
- 🐛 Bug fixes
- 🎨 UI/UX improvements
- ✨ New features or suggestions
- 📝 Documentation
- 🌍 Translations / localization
No contribution is too small. Even fixing a typo helps!

## Tech Stack
 
- **Frontend:** React + Vite
- **Styling:** CSS / Tailwind
- **Deployment:** Vercel
